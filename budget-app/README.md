# 고정비 가계부

고정비 점검 + 가계부를 한 화면에서 관리하는 웹앱 (HTML 파일 1개, 설치·서버 불필요).

## 사용법
`index.html`을 브라우저로 열면 바로 사용 가능. 데이터는 해당 기기 브라우저(localStorage)에 저장됩니다.

## 기능
- **대시보드**: 월 수입/지출(고정·변동 분리), 남은 돈·저축률, 고정비 진단, 다가오는 결제 D-day, 카테고리별 지출·예산 초과 표시
- **가계부**: 수입/지출 기록, 날짜별 그룹, 필터(수입·변동·고정), 수정/삭제
- **고정비 점검**: 월/연 단위 고정비 등록, 필수·유지·검토·해지 표시, 소득 대비 비율 진단(50% 기준), 절감 시뮬레이션(1년·3년), 자동 점검 리포트(구독 중복·통신비·보험 비중·자동저축 여부)
- **고정비 → 가계부 반영**: 버튼 한 번으로 이번 달 고정비를 가계부에 자동 기록 (중복 방지)
- **설정**: 월 소득, 카테고리별 예산, JSON 백업/복원, CSV 내보내기(엑셀용), 예시 데이터

## 배포·공유
- **claude.ai 링크로 공유**: 아티팩트의 공유(Share) 메뉴에서 공개 범위를 설정. 로그인한 사용자는 각자 개인 클라우드 영역에 저장되어 서로의 기록을 볼 수 없음(만든 사람 포함). 로그인 없이 공개 링크로 연 사람은 자기 기기 브라우저에만 저장됨.
- **직접 호스팅**: `index.html` 한 파일을 GitHub Pages, Netlify 등 아무 정적 호스팅에 올리면 됨(이 경우 기기 브라우저에 저장).
- 처음 여는 사람에게는 시작 안내 화면이 나오고, "예시 데이터로 둘러보기" 후 "지우고 시작"으로 바로 본인 데이터 입력 가능.
